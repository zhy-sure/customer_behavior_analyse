# Olist 巴西电商数据分析 — 客户价值 × 地理增长

> **从商业问题出发 → 用数据给出答案 → 输出可执行策略**

基于巴西最大电商平台 Olist 官方面试数据集（10 万+订单，2016-2018 年真实交易）的商业分析项目。不是做描述性统计的"学生作业"，而是聚焦具体商业问题，输出一份数据分析师交付给业务方的完整分析报告。

---

## 为什么做这个项目？

大多数数据分析作品集停在"我画了几张图"。这个项目从商业问题开始：

> **"谁是我们最有价值的客户？营销预算应该投到哪些城市和品类？"**

通过 **RFM 客户分层 + 地理增长机会分析** 的组合，展示了数据分析全流程：从凌乱的原始数据，到面向管理层的可执行建议。

## 分析框架

### 第一阶段：RFM 客户分层

```
原始订单 → 按客户计算 R/F/M 三个维度
         → 用 K-Means 将客户聚为 5 类
         → 刻画每类客户的画像（客单价、品类偏好、支付习惯、地域分布）
         → 识别"高价值一次性买家" vs "沉睡客户" vs "复购客户"
```

**核心指标：**
- **Recency（最近一次购买距今多少天）：** 越小越好
- **Frequency（累计购买次数）：** 越多越忠诚
- **Monetary（累计消费金额）：** 越高价值越大

### 第二阶段：地理增长分析

```
客户地理数据 → 按城市聚合：订单量、收入、客单价、增长率
             → 交叉品类数据：哪些品类在哪些城市卖得好？
             → 识别"高增长 + 低渗透"的潜力市场
             → 用增长机会得分给城市×品类组合排名
```

**增长机会得分** = 品类本地份额 × 城市增长率 × 市场规模

## 快速开始

### 环境要求
- Python 3.8 及以上
- （可选）MySQL 8.0+，如果要用 SQL 方式提取数据

### 安装

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/olist-business-analytics.git
cd olist-business-analytics

# 安装 Python 依赖
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 运行分析

```bash
# 运行 RFM 客户分层分析
python scripts/rfm_analysis.py

# 运行地理增长分析
python scripts/geo_growth_analysis.py
```

两个脚本都会在 `outputs/` 目录下生成可视化图表和 CSV 数据。

## 分析思路：商业叙述框架

*本项目采用结构化的商业叙述方式：*

```
我发现了 [数据事实]
  → 这说明 [商业洞察]
  → 因此我建议做 [具体行动]
```

**示例：**
> **我发现** 2.5% 的"高价值一次性买家"贡献了 18% 的总收入，人均消费 R$1,171，偏好品类是健康美容和手表礼品。
>
> **这说明** 存在一小批有强消费意愿但尚未复购的客户，他们对中高端品类有明显偏好。
>
> **因此我建议** 针对这批客户设计"第二单专属优惠"活动，推送其已购品类的关联商品；同时将其消费特征作为种子人群，用于 Facebook/Google 广告的 Lookalike 投放。

## 实际分析发现（节选）

| 发现 | 数据 | 商业含义 |
|------|------|----------|
| 客户高度一次性 | 97% 的客户只购买一次 | 复购率提升是最大的收入杠杆 |
| 收入高度集中 | SP/RJ/MG 三州贡献 62.6% 收入 | 核心市场要守住，二线城市是增长点 |
| 二线城市爆发增长 | São José dos Campos 增长 20,633% | 存在被低估的区域市场 |
| 高价值客户画像清晰 | 偏好信用卡支付，集中购买健康美容和手表礼品 | 可复制画像做精准获客 |
