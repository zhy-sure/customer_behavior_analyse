# 客户消费行为分析

> **Python + MySQL + Power BI | 3,900 条零售交易记录 | 端到端数据分析**

---

## 项目概述

基于某零售企业 3,900 条真实交易数据，完成从数据清洗、特征工程、SQL 查询到 Power BI 可视化看板的完整分析流程，输出可支撑业务决策的商业洞察。

---

## 数据概览

| 维度 | 指标 |
|------|------|
| 数据量 | 3,900 条交易记录 |
| 时间范围 | 单期截面数据 |
| 维度数 | 20 列（含 3 个特征工程列） |
| 覆盖范围 | 美国 50 州，4 个品类，25 种商品 |

### 核心指标

| 指标 | 数值 |
|------|------|
| 总收入 | $233,081 |
| 平均客单价 | $59.76 |
| 平均评分 | 3.75 / 5.0 |
| 复购率（回头客+忠实客户） | 97.9% |

## 分析流程

```
数据加载 → 数据清洗 → 特征工程 → 写入 MySQL → SQL 分析 → Power BI 看板
```

| 阶段 | 工具 | 产出 |
|------|------|------|
| 数据清洗 | Python (Pandas) | 填充缺失评分、删除冗余列 |
| 特征工程 | Python (Pandas) | 年龄段、购买频率天数、客户分层 |
| 数据库写入 | Python (SQLAlchemy + PyMySQL) | MySQL 数据表 |
| SQL 分析 | MySQL Workbench | 10 条业务查询 |
| 可视化 | Power BI | 3 页面交互看板 |

---

## 10 条 SQL 业务查询

| # | 问题 | 洞察 |
|----|------|------|
| Q1 | 男女客户收入对比 | 男性贡献 68% 收入 |
| Q2 | 折后高消费客户 | 识别"不差钱但爱折扣"的优质人群 |
| Q3 | 评分 Top 5 商品 | 口碑商品清单 |
| Q4 | 快递类型 vs 客单价 | 两日达客单价最高 |
| Q5 | 订阅 vs 未订阅 | 两者差异不大，订阅策略需优化 |
| Q6 | 折扣使用率 Top 5 | 折扣依赖度最高的商品 |
| Q7 | 客户分层 | 忠实客户占 79.6% |
| Q8 | 各品类 Top 3 商品 | 各品类王牌产品 |
| Q9 | 老客户订阅率 | 重复购买 ≥5 次的客户订阅意愿 |
| Q10 | 年龄段收入贡献 | 青年（18-30）消费最高 |

## Power BI 看板

| 页面 | 内容 |
|------|------|
| 概览 | KPI 卡片 + 性别环形图 + 品类柱状图 |
| 客户分析 | 客户分层饼图 + 订阅对比 + 年龄分布 + 散点图 |
| 商品分析 | 畅销 Top 10 + 品类×季节矩阵 + 评分排名 |

三页支持性别、品类、季节、客户类型切片器联动。
